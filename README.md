# Java Snake Game

## Project Description

A simple Snake Game developed using Java. The game provides a basic graphical interface where the player controls the snake, collects food, and tries to achieve a high score.

## Technologies Used

- Java
- Java Swing
- AWT

## Features

- Snake movement using keyboard controls
- Food generation
- Score tracking
- Game-over condition
- Simple graphical user interface

## How to Run

1. Download or clone this repository.
2. Open the project in a Java-supported IDE.
3. Compile the Java files.
4. Run the main Java class.
