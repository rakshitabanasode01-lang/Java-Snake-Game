# Java Snake Game

## 📌 Project Description

A simple Snake Game developed using Java Swing. The player controls the snake using keyboard keys, collects food, and increases the score.

## 🛠️ Technologies Used

- Java
- Java Swing
- AWT

## ✨ Features

- Keyboard-controlled snake movement
- Food generation
- Score tracking
- Game-over condition
- Graphical user interface

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project in a Java IDE.
3. Compile the Java files.
4. Run the main Java class.
